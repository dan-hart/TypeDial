# Changelog

## Unreleased

- Added GPLv3 licensing, third-party notices, and contributor documentation.
- Added GitHub Actions checks for native layouts, offline settings, and the design playground.

## 0.1.1

- Replaced named digit sizes with a 1 pt stepper and direct entry. Saved sizes carry over at the equivalent point size.
- Updated the offline playground to use the same size control and retain a separate value for each watch.

## 0.1.0

- Added the hybrid analog and digital face for Pebble Time 2, Pebble 2 Duo, and Pebble Round 2.
- Added offline settings, live and sample previews, Atkinson Hyperlegible digits, optional seconds and dial marks, and color presets.
- Added larger digit sizes, a preview pinned above Save, and solid backgrounds.
